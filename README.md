# MyCashbook Pro — GitHub Signed APK Setup

## Included Files
- `www/index.html` — Login & Register system (PIN + Password), compact spacing, fast offline execution, Monthly tabs, Carry-Forward balance, Last 5 entries view, Hindi/English entries, Popup Edit, Excel export, Portrait print.
- `assets/icon.png` — Custom MyCashbook Pro wallet + growth bar + gold coin app icon.
- `.github/workflows/build-signed-apk.yml` — Automatically applies the icon, enables R8 speed optimization, signs the APK, and uploads `app-release.apk`.
- `package.json` & `capacitor.config.json` — Android Capacitor build config.
